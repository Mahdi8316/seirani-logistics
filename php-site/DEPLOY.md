# راهنمای انتشار روی cPanel (نسخه‌ی PHP)

این نسخه با **PHP + MySQL** است و روی هر cPanelی بدون Node، بدون Terminal و بدون
build اجرا می‌شود. کل کاری که باید بکنی: یک دیتابیس بساز، یک فایل را ویرایش کن،
فایل‌ها را آپلود کن.

## پیش‌نیاز
- PHP نسخه‌ی ۷٫۴ یا بالاتر (تقریباً همه‌ی هاست‌ها دارند؛ از «Select PHP Version»
  می‌توانی نسخه را روی ۸.x بگذاری — بهتر است).
- یک دیتابیس MySQL (همه‌ی cPanelها دارند).

## گام ۱: ساخت دیتابیس MySQL
در cPanel → **MySQL® Databases**:
1. یک **New Database** بساز (مثلاً `seirani`). نام کامل آن می‌شود چیزی مثل
   `cpaneluser_seirani`.
2. پایین‌تر، یک **MySQL User** بساز (نام‌کاربری + رمز). نام کامل مثل
   `cpaneluser_dbuser`.
3. در بخش **Add User To Database**، کاربر را به دیتابیس اضافه کن و **ALL
   PRIVILEGES** را بزن.

نام کامل دیتابیس، نام کامل کاربر و رمز را یادداشت کن.

## گام ۲: ویرایش فایل تنظیمات
فایل **`inc/config.php`** را باز کن و این‌ها را پر کن:
```php
define('DB_NAME', 'cpaneluser_seirani');   // نام کامل دیتابیس
define('DB_USER', 'cpaneluser_dbuser');    // نام کامل کاربر
define('DB_PASS', 'رمز-دیتابیس');
define('ADMIN_USERNAME', 'admin');
define('ADMIN_PASSWORD', 'یک-رمز-قوی');     // رمز ورود به پنل
define('SITE_URL', 'https://your-domain.ir');
```
> اگر سایت را در زیرپوشه گذاشتی (نه ریشه‌ی دامنه)، `BASE_PATH` را هم مثل `'/sub'`
> بگذار.

## گام ۳: آپلود فایل‌ها
**محتوای پوشه‌ی `php-site` را** در `public_html` (یا پوشه‌ی دامنه‌ات) آپلود کن.
- در cPanel → **File Manager** → وارد `public_html` شو → **Upload**.
- ساده‌ترین راه: از کل `php-site` یک فایل **zip** بگیر، آپلود کن، و در File Manager
  **Extract** کن؛ سپس فایل‌های داخلش را به `public_html` منتقل کن (طوری که
  `index.php` مستقیماً داخل `public_html` باشد).

## گام ۴: تمام!
مرورگر را باز کن:
- سایت: `https://your-domain.ir`
- پنل مدیریت: `https://your-domain.ir/admin` (ورود با `ADMIN_USERNAME` /
  `ADMIN_PASSWORD`)

در نخستین بازدید، جدول‌های دیتابیس خودکار ساخته و با محتوای اولیه پر می‌شوند.

---

## نکات
- **تغییر محتوا:** همه‌چیز از پنل `/admin` قابل ویرایش است (مقالات، خدمات با آپلود
  آیکون، متن بخش‌ها، صحنه‌های مسیر، و مشاهده‌ی پیام‌های فرم تماس).
- **امنیت:** پوشه‌ی `inc/` (شامل رمز دیتابیس) با فایل `.htaccess` از دسترسی وب
  بسته شده است. حتماً `ADMIN_PASSWORD` را عوض کن.
- **آیکون خدمات** داخل دیتابیس ذخیره می‌شود (نیازی به پوشه‌ی قابل‌نوشتن نیست).
- **ویدیوها** در پوشه‌ی `assets/` هستند؛ در صورت نیاز جایگزینشان کن (همان نام‌ها).
- **پشتیبان‌گیری:** از دیتابیس در phpMyAdmin خروجی (Export) بگیر.
- اگر صفحه‌ی سفید دیدی، از «Select PHP Version» نسخه‌ی PHP را ۸.۰+ کن و مطمئن شو
  افزونه‌ی **pdo_mysql** فعال است (معمولاً هست).
